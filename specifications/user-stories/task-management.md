# ✅ Task Management - User Stories

## 📋 Overview
User stories related to creating, editing, and managing tasks.

## ➕ Task Creation
- [x] Simple task creation form with title and description
- [x] Set priority (High, Medium, Low)
- [x] Set category (choose existing or create a new one)
- [x] Add due date (default is today)
- [x] Create subtasks within a task (Optional)
- [x] Basic field validation

## ✏️ Task Editing
- [x] Edit task title, description
- [x] Change priority level
- [x] Change category (choose existing or create a new one)
- [x] Edit subtasks (add, remove, modify)
- [x] Mark as completed/incomplete

## 🔧 Subtask Management
- [ ] Create subtasks within main tasks
- [ ] Edit subtask title and description
- [ ] Mark subtasks as completed
- [ ] Delete individual subtasks
- [ ] Subtask completion counter
- [ ] Change subtask order (order = subtask priority)

## 🗑️ Task Deletion
- [ ] Delete with confirmation dialog
- [ ] Delete subtasks when deleting main task
- [ ] Simple task removal

## 🏷️ Task Priority
- [ ] Three priority levels: High, Medium, Low
- [ ] Visual priority indicators
- [ ] Priority for task categorization

## 🏷️ Basic Category Operations
- [ ] Set category when creating tasks (choose existing or create new)
- [ ] Change task category during editing
- [ ] Filter tasks by category
- [ ] View tasks grouped by category
- [ ] See detailed category management in `category-management.md`

## 📅 Basic Scheduling
- [ ] View tasks by date
- [ ] Simple date selection
- [ ] Default date is today
- [ ] Due date for task planning
